# ADR-0002：通信与身份

**状态**：已锁定（v1）

## 背景

"这台机器是谁"在这个系统里不是一次性的登录问题，它同时决定四件事：谁的成绩算谁的、
代码收到哪个目录、下发文件落到哪、升级包发给谁。整间机房用**同一份镜像**装出来，
所以从镜像里带出来的任何东西都**不能**当身份用 —— 50 台机器会带着同一份身份开机。

同时，"配对"这个动作必须由人在场完成：机器注册上来时服务端只知道"有一台机器"，
不知道它前面站着谁。

## 决定

| 项 | 决定 |
|---|---|
| 认证 | 每机独立 Token，服务端只存 `sha256(token)`，按机吊销 |
| 机器身份 | `machine_uuid`（首选）+ SMBIOS 指纹（快照还原兜底）；`machine_id` **只供人工辨认** |
| 配对 | 镜像统一密钥注册 + **六位数字配对码**绑定到名单条目（**人**）；配对**永久** |
| 关系 | **一人一机、一机一人**，服务端双向强制；覆盖绑定必须走显式「改派」 |
| 场次 | 多场次隔离（`contest_id`）；机器绑的是人，场次**动态解析** |
| 后台账号 | 单管理员 |
| 网络 | 考场同一内网、双向可达（v1 不用 Ansible，留作以后备选） |
| 防篡改 | 完整性校验 + 审计日志，**不干预选手** |

**配对码是六位数字**，只存哈希、限时 30 分钟、一次性、需管理员鉴权。它只在"绑定
的那一刻"用；配对之后认机器一律靠 `machine_uuid`。取六位的原因是它要在机器屏幕和
教师眼睛之间传递，越长越抄错；而"限时 + 一次性 + 管理员鉴权"已经把爆破空间压没了。

**每一次 tick 都要把这个码发回去**（`claimed=false` 的机器），所以明文必须在服务端
**内存里**留到过期或配对为止 —— 库里只有哈希，推不回明文。

## 后果

- **配对一次，之后 N 场比赛零人工**：换场次、系统重装、快照还原、升级 Agent 都不用
  重新配对（见 [`../design/04-server.md`](../design/04-server.md) §4.6）。
- **快照还原能自愈**：注册时带硬件指纹（SMBIOS UUID，还原后不变），服务端按它认回
  原来那台机器、保留配对关系。但这条有一条硬前提：**那台机器当前必须离线** ——
  指纹只证明硬件相同，克隆镜像的机器报的也是同一个指纹。
- 配对码明文只活在内存里，代价是**服务端重启后下次 tick 会发一个新码**，
  桌面文件跟着更新。
- 未配对状态**不另立表**：就是 `agent.roster_entry_id IS NULL`。
- 链路上只有两样凭据：装机时的**统一注册密钥**（一次性）与注册换来的**本机 token**
  （长期）。**配对码不是凭据**，它是"教师此刻在场"的一次性证明。

## 被否掉的替代方案与理由

* **每选手一个注册码**（`enroll_code`）。它适合临时加人、小规模现场发码，但**没法
  规模化**：整间机房用同一份镜像时，逐台发码等于把 50 次人工塞进开考前那十分钟。
  这条链路是**删除**、不是并存 —— 两种模式并存意味着每种都要维护、测试，并且迟早
  有人选错。`agent.ini` 里若还留着 `enroll_code =`，它会被静默忽略（升级过来的机器
  不该因为这个起不来）。
* **把 `machine_id`（`/etc/machine-id`）当身份**。克隆镜像没做通用化时它是**整批
  相同**的，拿它当身份等于让整批机器共用一个身份，而且是静默的。
* **配对之后下发密钥**。讨论里曾被当成链路的一步（"配对后自动下发密钥验证"），但它
  不需要存在：机器在**注册那一步**就已经拿到凭据了，配对的全部作用是把那枚凭据绑到
  人。加进来只会多一处能失效的地方。
* **一份镜像带一份机器身份**（把 `credential.json` 烤进镜像）。每台克隆机会带着
  **同一个身份**开机、互相覆盖，而文件是**静默错的** —— 一切正常，只有成绩
  会对不上人。安装器会在状态目录里发现残留身份文件时告警，但那是事后发现。
* **长配对码 / 大小写字母混合码**。它换来的是熵，但教师在屏幕上抄错一次就得
  重来一次；而安全边界本来就不靠它。
* **把配对码当成一次性登录凭据**（每次干活都要码）。那样"桌面上的码还准不准"就变成
  一个客户端状态问题，而 Agent 的状态目录恰恰是最先被快照还原抹掉的东西。
* **多管理员 / 角色权限**。v1 的规模是一间机房、一个教师，加进来的是完整的权限模型
  和它的测试面；单管理员能覆盖现场。
