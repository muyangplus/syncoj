# ADR-0005：公开端口

**状态**：已锁定（v1）

## 背景

- 考场地址由教师口头告诉学生：`http://10.0.0.5/` 比 `http://10.0.0.5:8000/` 易传达；浏览器对 http 默认走 80。
- 管理界面与全部 API 在同一进程；学生访问同一端口会看到**登录框与接口地图**（`/docs` 免登录列出全部管理接口）。

## 决定

服务端**默认再开一个监听**（`SYNCOJ_PUBLIC_PORT`，默认 80）：

| 端口 | 上面有什么 |
|---|---|
| `--port`（默认 8000） | 全部：管理界面 + 三套 API + `/docs` |
| `SYNCOJ_PUBLIC_PORT`（默认 80） | 只有 `/install` 与 `/player`；管理端、`/docs`、`/openapi.json`、`/healthz` 一律 404 |

- `SYNCOJ_PUBLIC_PORT=0` 关掉第二个监听（`0` 是哨兵：留空等于没设，会退回 80）。
- 门禁是**黑名单**（挡 `/api/v1/admin`、`/docs`、`/redoc`、`/openapi.json`、`/healthz`）。
- 被挡接口回 **404 不回 403**。
- "是否来自公开端口"由服务端**启动时**写进 `app.state.public_port`，判据是真的在该端口监听，不是配置数字。
- 服务端在公开端口的 `index.html` 注入 `window.__SYNCOJ__={"publicOnly":true,"adminPort":8000}`（`web/src/publicMode.ts`），前端据此把默认与兜底路由压到 `/player`，**不碰鉴权状态**。

## 后果

- 绑不上 80 时服务端**降级**（只留管理端口并打印两种修法）；降级后无请求被当成公开端口，管理界面不受影响。
- `adminPort` 供**装机命令**使用：命令里的地址长期写进机器配置，指向 API 端口而非可关闭的公开端口；主机名取当前页面（见 [`../design/07-ops-and-install.md`](../design/07-ops-and-install.md) §7.3）。

## 被否掉的替代方案

* **同一端口按路径分**：学生访问的原点上就有登录框，`/docs` 免登录列出全部管理接口。
* **只放行两页的白名单门禁**：漏一条即两页静默失效（白屏、转圈）；黑名单漏一条只多暴露一个仍有 `require_admin` 的接口。
* **403**：等于提示"去别的端口试"。
* **判据取配置端口号**：降级后与事实不符；`TestClient` 默认端口是 80，会把整个测试套件误判为公开端口。
* **给考场机器用非特权端口（如 8080）**：地址靠口头传递，多出的端口号增加出错次数。
* **前端自己数端口**：80 端口时 `location.port === ""`；同一事实定义两遍。
