# ADR-0010：`{home}` / `{desktop}` 恒按**运行账号**展开

**状态**：已锁定（v1，真机故障后补上）

## 背景

- 问题：路径模板（`scan.roots = {desktop}/{player_no}`、`deploy_root = {desktop}`）展开成**哪个用户**的家目录。
- 真机故障：注册单元以 **root** 运行，按当前进程用户展开得到不存在的 `/root/桌面`，配置校验失败、注册退出 2；journal 只报"扫描目录的父目录不存在"，机器不出现。
- 执行安装的账号不一定是运行 Agent 的账号；跨用户授权易出现"服务在跑但什么都不传"。

## 决定

- **`{home}` / `{desktop}` 恒按运行账号解析**（`[agent] run_user`），与当前进程是谁无关。
- **运行账号默认 = 执行安装的账号**（显式 `--user` 才建专用账号），安装器把它写进 `run_user`；`run_user` 留空退回当前用户（手工部署、排障用）。
- `{desktop}` 探测：先读 `<运行账号的家>/.config/user-dirs.dirs` 的 `XDG_DESKTOP_DIR`，再试 `~/桌面`、`~/Desktop`、`~/desktop`。
- `{desktop}` / `{home}` **载入配置时展开**；`{player_no}` / `{contest_slug}` **注册拿到凭据后展开**，之前原样保留不报错；注册后 Agent 在启动日志打出最终目录。

## 后果

- 注册单元以 root 跑也解析到运行账号的桌面，绝不落到 `/root`。
- 状态目录属主跟随运行账号（`agent.ini` 与状态目录文件都 chown 给它）；漏 chown 表现为"装完起不来"或"一直重新注册"（报权限错），安装器检查并告警。
- 安装器**必须**写入 `run_user`，否则 root 注册单元退回 `/root`。
- 单元不设 `ProtectHome=read-only`（[ADR-0008](ADR-0008-systemd-unit-hardening.md)）：Agent 要往桌面写配对码。

## 被否掉的替代方案

* **按当前进程用户展开**：root 注册单元展开成 `/root/桌面`，失败且报错不指向原因。
* **强制专用账号 `syncoj`**：其家目录不是选手桌面；跨用户授权易出现"什么都不传"。
* **探测"当前登录的图形用户"**：开机自启时常无人登录，`who`/xdotool 类判据无结果。
* **展开不了就报错**：校验在注册前，`{player_no}` 尚无值，"未注册"会被误报为"配置错"。
* **只认 `~/Desktop`**：中文 NOI Linux 上是「桌面」。
* **状态目录放运行账号家目录下**：root 写（注册单元写凭据）与运行账号读的权限边界不清；用 `/var/lib/syncoj` + chown。
