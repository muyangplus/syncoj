# ADR-0010：`{home}` / `{desktop}` 恒按**运行账号**展开

**状态**：已锁定（v1，真机故障后补上）

## 背景

Agent 配置里支持路径模板：`scan.roots = {desktop}/{player_no}`、
`deploy_root = {desktop}`。占位符要展开成某个**具体的家目录**，而问题就是
"哪个用户的家目录"。

**真机故障**：注册单元 `syncoj-agent-enroll.service` 以 **root** 跑，
于是按"当前进程的用户"展开就得到 `/root/桌面` —— 而那台机器上根本不存在这个目录：

```
配置校验失败 → 注册直接失败、退出 2
```

而 journal 里看不到原因（报的是扫描目录的父目录不存在），表现是"机器永远不出现"。

同一类的第二个来源：**安装 Agent 的账号**不一定是将来跑 Agent 的账号。
跨用户授权在现场很容易装成"服务起来了但什么都不传"。

## 决定

- **`{home}` / `{desktop}` 恒按「运行账号」解析** —— 也就是 `[agent] run_user`
  指定的那个账号，而**与"当前是谁在跑这个进程"无关**。
- **运行账号默认 = 跑安装的那个账号**（显式 `--user` 才创建专用账号）；
  安装器会把"跑安装的那个账号"写进 `run_user`。
- `run_user` **留空则退回当前用户**（手工部署、自己跑排障时用）。
- `{desktop}` 自动探测：先读 `<运行账号的家>/.config/user-dirs.dirs` 里的
  `XDG_DESKTOP_DIR`，再依次试 `~/桌面`、`~/Desktop`、`~/desktop`。
  （兼容「桌面」与 `Desktop` 两种命名。）
- 四个占位符分两类：`{desktop}` / `{home}` **载入配置时就展开**；
  `{player_no}` / `{contest_slug}` **等注册拿到凭据后再展开**。
- 后两个在注册之前**原样保留，不报错**；注册完成后 Agent 在启动日志里打出
  最终展开的目录。

## 后果

- 注册单元以 root 跑也没关系：它照样解析到**那个账号**的桌面，绝不落到 `/root`。
- 状态目录的属主跟着运行账号（`agent.ini` 与状态目录里的文件都 chown 给这个账号）。
  漏掉 chown 的表现是"装完起不来"或"一直重新注册"，而报的是权限错误 ——
  很难联想到属主问题，所以安装器现在会检查并告警。
- `run_user` 留空退回当前用户，所以注册单元以 root 跑时**必须**让安装器把它写进去；
  没写就会退回 `/root`，又回到那个故障。
- 配置校验发生在注册之前，所以"展开不了的占位符原样保留"是必须的：
  按"配置错了"报错是误报。
- `protectHome` 不能设成 `read-only`（见 [ADR-0008](ADR-0008-systemd-unit-hardening.md)），
  因为 Agent 要往那个桌面写配对码。

## 被否掉的替代方案与理由

* **按当前进程用户展开**（最自然的写法）。见背景：注册单元是 root，展开成
  `/root/桌面`，注册直接失败退出 2，而报错指不到真正的原因。
* **强制创建一个专用账号**（`syncoj`），所有机器都用它。那会让"代码和下发文件都在
  选手自己的桌面上"变成一句空话：专用账号的家目录和选手的桌面是两个地方，
  而选手不会去专用账号的家目录里写代码。跨用户授权在现场很容易装成
  "服务起来了但什么都不传"。
* **让 `{desktop}` 探测"当前登录的图形用户"**。一台机器可能没人登录（开机自启
  Agent 的常态），xdotool/who 那类判据在无人登录时给不出答案；
  而"运行账号"这个判据任何时候都成立。
* **展开不了就报错**。配置校验发生在注册之前，那时 `{player_no}` 本来就还没有值；
  报错会把"还没注册"说成"配置错了"。
* **只认 `~/Desktop`（英文名）**。中文 NOI Linux 上是「桌面」，硬编码一种命名会在
  一半的机器上找到不存在的目录。先读 `user-dirs.dirs` 再逐个试，是这个问题的
  正确答案（XDG 本来就是为此存在的）。
* **把状态目录也放到运行账号的家目录下**。状态目录要 root 写的部分（注册单元写
  凭据）与运行账号读的部分在同一处，放家目录下会让权限边界变得含糊；
  `/var/lib/syncoj` + chown 更直白。
