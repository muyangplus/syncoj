## 5. 接口约定与前端

### 5.1 协议一致性靠契约测试，不靠共享模型

Agent 零依赖、**不能 import pydantic**，所以一致性靠 **CI 契约测试**：

```python
# server/tests/test_agent_contract.py
def test_tick_payload_matches_schema():
    raw = subprocess.run(["python3", "agent/tools/build_fixture.py"],
                         capture_output=True, text=True).stdout
    TickRequest.model_validate(json.loads(raw))     # 不匹配就红
```

`agent/tools/build_fixture.py` 用 Agent 自己的纯标准库构造器生成真实 payload；服务端 schema 一改破了契约，CI 立刻拦住。

### 5.2 管理端 API：一个信封、一个错误体

完整约定见 [`docs/reference/api-conventions.md`](../reference/api-conventions.md)。

```jsonc
// 所有列表
{ "items": [ … ], "total": 137, "limit": 50, "offset": 0 }

// 所有错误
{ "detail": "这句是给人看的中文", "code": "roster_entry_taken", "details": { } }
```

统一形状是为了让**前端只写一次数据层**，否则列表/错误每种写法都要逐接口适配。

- **`detail` 永远是字符串**，一句能直接贴到提示条上的中文。422 由处理器揉成"每页条数太大了（最大 500）；考号不能为空"，原始错误列表留在 `details.errors` 给表单标红。
- **500 必须有兜底处理器**：否则 Starlette 返回纯文本 `Internal Server Error`，前端 `response.json()` 抛 `SyntaxError`，界面只显示 "Unexpected token I"。
- **码表静态可查**：`ERROR_CODES` 是唯一清单，`CODE_BY_STATUS` 是"没显式给码时按状态码推"的兜底表。四条规矩由 AST 扫描守着：发出的码必须登记、登记的码必须真会发出、兜底码必须登记、用得到的状态码必须有兜底。死码不许留，因为它会被当成契约（前端照写分支、文档照写章节）。

### 5.3 前端架构

类型链路单向，唯一真相源是服务端 schema：

```
server/syncoj_server/schemas.py        ← 类型的唯一来源
        │  python server/tools/dump_openapi.py
        ▼
web/openapi.json
        │  npm run gen:types  (openapi-typescript)
        ▼
web/src/api/schema.d.ts                ← 生成物，不要手改
```

页面**只描述长什么样，不描述怎么取数**：

| 文件 | 职责 |
|---|---|
| `api/client.ts` | `request`/`query`/`download`，把错误体转成带 `code` 的 `ApiError` |
| `api/endpoints.ts` | 所有路径的唯一定义，服务端改路径只改这一处 |
| `api/crud.ts` | 分页、信封、删除语义的公共实现 |
| `api/<资源>.ts` | **一个资源一个模块**，只有「路径 + 参数 + 返回类型」映射 |
| `api/index.ts` | 入口，几乎全是 re-export；页面只从这里 import |
| `composables/useList.ts` | 分页、筛选、加载/错误、刷新、批量选择、可中断请求 |
| `composables/useMutation.ts` | 写操作、提示、刷新列表、按钮 pending 态 |
| `components/` | `PageShell` / `DataTable` / `ConfirmByNameDialog` / `FormDialog` |

- 新增资源 = 一个资源模块 + 一个页面（+ `index.ts` 一行转出），不再抄一遍 loading/error/分页/轮询。
- 按资源拆模块而不堆进一个 `index.ts`，否则几十个方法挤在一个文件里，漏接入口很难看出来。

#### 界面文案：只留动作、后果与实时数据

页面**禁止**声明式/解释式语句。允许的只有：

| 允许 | 例子 |
|---|---|
| 标题、标签、按钮、状态、表头、placeholder | 「统一密钥」「已签名」「sha256」 |
| **一句话**操作指引 | 「在每台空机器上跑它。」 |
| **破坏性动作的后果** | 「会删掉统一注册密钥与本机凭据。」 |
| 服务端原文错误、实时数据 | `detail` 直接显示，不加工成第二种说法 |

- 删掉成段说明（设计理由、概念辨析、机制、「上传不等于铺开」这类劝告），它们属于文档。
- 判据是**站在机器前的人此刻能否据此动手**：不能动手的解释句删，能动手的后果句留（删东西前必须让人知道会丢什么）。
- 面向用户的字符串不许出现 Markdown 标记（如 `**已铺开**`），由 AST 守卫把关（`server/tests/test_errors.py` 连同前端文案）。

### 5.4 删除语义

判据："删掉之后还有没有人需要它"。

- **结构性数据**（名单/场次/选手/机器/题目）→ 硬删，**确认方式是输入名称**（`confirm` 必须逐字等于 `player_no` / `slug` / `name` / `hostname`），服务端校验。"是否确定"弹窗在连续操作里会被肌肉记忆点掉，打名称不会。
- **产物性数据**（代码文件/下发资产）→ 教师删除也**硬删**（不要求输名称；清空代码台账要输场次 slug）；内容寻址的 blob 在无任何记录引用时才一并删除；`source/` 里已落盘的文件不碰。
- 唯一的墓碑是**扫描对账**打的"已消失"（选手在机器上删掉的文件，`deleted_at`），`?include_deleted=true` 可见；导出**默认带上**，因为"选手确实交过，只是后来删了"。见 [`ADR-0003`](../decisions/ADR-0003-delete-semantics.md)。

### 5.5 下发资产一律是文件，不解压

题面与样例本身就是 zip，服务端**只搬运字节**，不打包不解压，由选手或评测机自己解压。
换来的是压缩格式上**零第三方依赖**，以及"落盘字节与教师手里那份逐字节相同"这一可验证性质。

**纯文本资产可在线改正文**（`GET|PUT .../assets/{id}/text`），改错别字不用重传：

* "改"是**同一个 asset id 换掉 `sha256`/`size`**，不新建；改名是另一条路（换标签不动内容）。两种后果对已落盘文件完全不同，合成一个入口会说不清回执。
* 改完把该资产**已完成（及已判失败）的下发目标重排回 `PENDING`**：tick 只对 `PENDING/READY` 派活，不重排就是"选手页新正文、机器上旧文件"。续传不错位：分片按**内容 sha256** 命名；完成回执也带 sha256，迟到的旧回执不会把新内容标成完成（管理端进度一并清零）。
* "能否在线改"由**服务端**算成布尔给界面（扩展名白名单 + 体积上限，只看元数据不读盘）；真正关卡在读写接口：必须能按 UTF-8 解码，否则 400，不把乱码送上考场机器。

**唯一例外：就地给 zip 打密码 / 改密码**（教师给这一场换题面密码，回本机重打包再上传没有额外价值）。由 `services/zipcrypto.py`（自写的 ZipCrypto 写实现）完成，**读仍走标准库**，让"写出的包能否读回"由独立实现判定。

* 与在线改正文同一套语义：同一 asset id 换 `sha256`/`size`，已完成/已失败目标重排回 `PENDING`。
* **库里没有密码字段**：密码只在自动生成/更新的 `password.txt` 文本资产里，教师可读回、可照常下发。审计事件**不写密码**，否则服务端多存一份明文。
* `password.txt` **单件语义**，更新同一条而非每次新建，否则列表里堆着几份同名文件，教师分不清哪份最新。
* 用 **ZipCrypto** 不用 AES：学生用 **Archive Manager**（GNOME file-roller）打开，它打不开 AES 包。口径是**挡随手翻看、挡不住有心人**（`password.txt` 本身是明文），不称"安全加密"。密码按 UTF-8；不支持 ZIP64（>4GB / >65535 条目回 400）。

### 5.6 两个免登录页面

管理界面之外有两页**故意免登录**，因为使用者手上不可能有管理凭据：

| 页面 | 谁在用 | 身份怎么确定 |
|---|---|---|
| `/install` | 教师，站在还没装 Agent 的机器前 | **不需要身份**：只展示从哪儿装、装哪个版本、怎么核对 |
| `/player` | 选手，在考场机器上 | **服务端按来源 IP 认机器** → 配对到的人 → 场次 → 该选手 |

**`/install`**：地址用**当前页面的 `origin`**（教师能打开它，说明这个地址在局域网可达），无需调要鉴权的"我是谁"接口。没铺开任何版本时不给安装命令，只给一句"去铺开"的指引。

**`/player` 身份**：链条「机器 → 人 → 场次里的选手」与 `/tick` **共用同一个解析函数**（../design/04-server.md §4.6 的 `resolve_machine`），否则会出现"tick 能干活、这页却说没有场次"的矛盾。
匹配不上（Agent 没起、教师用笔记本打开）才给**手填场次 + 考号**的兜底入口；**不用 URL 参数预填**，否则"显示的是谁"取决于一个可随手改的链接。

**`/player` 内容**：只有**考场公告**、发给他的文件清单、身份卡；**不含代码、成绩、别人**（有测试，"别的选手的资产不许出现"是真会红的那条）。

- 顺序：**场次卡 → 考场公告 → 下发文件**。公告是"这一场"的话，放在场次标题下才读得通。
- 场次卡给**开考与结束时间**（留空 = 不限）：到点后服务端拒收文件，选手需要提前知道。时间按服务端存值原样下发（UTC ISO），浏览器按本机时区显示，与教师填的钟点一致。
- **公告就是下发文件里的 `NOTICE.md`**，不另配文本：教师在「文件下发」页写一个 `NOTICE.md` 照常下发即可。理由同 ../design/05-api-and-frontend.md §5.5 —— 另设公告字段等于写两遍，还要解释哪个作数。
- 判据：**本场 + 发给他本人**的下发记录里 basename 大小写不敏感匹配 `notice.md`，多份取最后下发的；非 UTF-8 或超过 64 KB 的跳过并记日志（不显示半截乱码）。
- 正文按 **Markdown 渲染**（`marked` + `DOMPurify`，见 `web/src/utils/markdown.ts`）。消毒不能省：正文常从别处粘贴，`<img onerror=…>` 会让这页执行任意脚本。
- 开 **`breaks: true`**（GFM 行为）而非 CommonMark 软换行合并：公告写在纯文本框里，写两行就该看到两行。
- **不从题目模式推导"把代码存到 X"**：服务端不知道每台机器的 `scan.roots` 与前缀，错的操作指引比没有更坏。

### 5.7 公开端口：默认 80，只放这两页

考场机器上浏览器敲 `http://10.0.0.5/` 默认走 80，所以服务端**默认再开一个监听**（`SYNCOJ_PUBLIC_PORT`，默认 80）：

| 端口 | 上面有什么 |
|---|---|
| `--port`（默认 8000） | 全部：管理界面 + 三套 API + `/docs` |
| `SYNCOJ_PUBLIC_PORT`（默认 80） | 只有 `/install` 与 `/player`；管理端、`/docs`、`/openapi.json`、`/healthz` 一律 404 |

- `SYNCOJ_PUBLIC_PORT=0` 关掉第二个监听；`0` 是哨兵，因为留空等于没设、会退回 80（见 `config._env_opt_int`）。
- **不在同一端口按路径分**：否则学生访问的原点上就有登录框，`/docs` 还能免登录列出全部管理接口。
- **门禁用黑名单**（挡 `/api/v1/admin`、`/docs`、`/redoc`、`/openapi.json`、`/healthz`）而非白名单：白名单漏一条是这两页悄悄坏掉（白屏、转圈，没人想到是门禁）；黑名单漏一条只是多暴露一个仍有 `require_admin` 兜底的接口。
- 被挡接口回 **404 不回 403**：这个端口上就没有它，403 等于指路"去别的端口试试"。
- **"是否来自公开端口"由服务端启动时写进 `app.state.public_port`**，判据是真的在那个端口上监听，而非配置数字：
  * `serve` 绑不上 80 时**降级**（只留管理端口并打印两种修法），此时不该有请求被当成公开端口，否则会连管理界面一起 404。
  * `TestClient` 默认端口恰好是 80，取配置默认值会让整个测试套件被误判为公开端口。
- **前端如何知道在公开端口**：服务端在公开端口返回的 `index.html` 注入 `window.__SYNCOJ__={"publicOnly":true,"adminPort":8000}`（见 `web/src/publicMode.ts`）。前端据此把默认与兜底路由压到 `/player`，**不碰鉴权状态**（该接口被挡），`/login` 也送到 `/player`。不让前端自己数端口：80 端口时 `location.port === ""`，且同一事实不该定义两遍。
- `adminPort` 给**装机命令**用：命令里的地址会长期写进机器配置，必须指向 API 端口而非可关掉的公开端口；主机名仍取当前页面（局域网真实可达的证据，见 ../design/07-ops-and-install.md §7.3 三条来源的排序）。
