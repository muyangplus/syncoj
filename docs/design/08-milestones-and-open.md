### 10.1 内置评测

**要做什么**：SyncOJ 自己编译、运行选手代码并对测试点判分，成绩直接进现有的成绩矩阵。
现在这一步在 SyncOJ 之外 —— SyncOJ 不触发评测，只收外部评测器（LemonLime / Arbiter）
写进 `judge_result/` 的结果（[`../reference/judge-result.md`](../reference/judge-result.md)）。

**这条与一条已锁定决策冲突**：`00-decisions.md` 里「评测对接 = 只投递 `source/` +
扫描结果目录回写成绩，**不触发评测**」是锁定的（连同
[`ADR-0001`](../decisions/ADR-0001-tech-stack-and-dependencies.md)）。落地前先按惯例改那条
决策、补一份 ADR 写明改动理由，不要先写代码。

**动手前要定的岔路**（每条都是选择题；未定就不动手）：

1. 评测跑在哪
   - A. 服务端本机：只有一处工具链、一处测试数据；代价是选手代码在服务端主机上执行，
     隔离与负载都压在服务端。
   - B. 派给机房里的 Agent：用机器上现成的编译器与空闲 CPU，服务端不扛评测；
     代价是逐机环境差异、占用考试机、结果要回传。
   - C. 按场次（或按题）二选一。
2. 隔离到什么程度
   - A. `setrlimit` + 独立运行账号：与 LemonLime 同级，不加新依赖。
   - B. cgroup v1（`systemd-run --scope`）：目标机的 systemd 245 支持，能管住整棵进程树。
   - C. nsjail / seccomp：隔离最强，但要往目标机上装新依赖。
3. 测试点数据从哪来
   - A. Web 上传 zip 进内容寻址的资产表：与现有下发同一条路（要不要与下发共用一张表另定）。
   - B. 指向服务端本地目录：与 `judge_result/` 同一种形态，教师自己放。
4. 谁触发
   - A. 交一次自动判一次。B. 教师点「评测」，含批量重测。C. 两者都要。
5. 语言范围：只 C++（NOI 的实际情况），还是加 C / Python（各要一套编译与限制）。
6. 判分范围：只逐点对错，还是也要 SPJ（特判）/ 交互题 / 子任务捆。

**落地时要一起改的**：

- `docs/design/04-server.md` §4.4 现在写的是"后台扫 `judge_result/`"；内置评测要在这条
  之外多一个成绩来源。
- 成绩矩阵的 `parse_status` 现在只有 `ok` / `unparsed` / `manual` / `missing`，要能区分
  「内置评测的」与「外部导入的」，否则重测与覆盖语义说不清。
- `judge_run` 现在只存到「选手 × 题」一个分数；内置评测要存测试点一级的结果、编译与
  运行错误，以及这条成绩是哪一版代码跑出来的（对得上 `source_file.revision`）。

### 10.2 已知限制

（这一轮主动留下的取舍，不是缺陷。）

* 上传时若让服务端生成随机密码，密码只落在 `password.txt` 这份文本资产里；上传回执是
  资产体，不为它新增字段。教师想当场拿到密码就走「文件下发」页那条「打包成 zip」。
* 「运行参数」（空闲心跳 / 有活心跳 / 离线判定）是**整间机房**生效，没有按机器、
  按场次的粒度。
* 安装时换密钥留下的 `bootstrap.key.replaced-<时间戳>` 备份不清理。
* 同版本重装是就地替换，没有同版本回滚点。
* 诊断包**每台机器只留最新一份**：不存历史，也不提供原始 gzip 下载（要留旧包，就在
  管理端读到之后自己存出去）。按机器的 60 秒限速窗口在内存里，服务端重启即重置 ——
  代价只是可能多收一份。

### 10.3 被明确否决的想法

不再重新提案：

* **违规判定 / 迟到上传告警**。曾经设计成"结束时间之后的上传记一条 `late_upload`
  违规事件、点名到人"，用户明确否掉了：考试结束后文件本来就不该再同步，服务端直接
  **不收**就够了；再去判定"谁违规"是把一个技术状态变成了对人的指控，而网络抖动、
  机器卡顿都会让正常选手撞上这条线。现在到点只做两件事：拒收（409
  `contest_ended`）+ 把场次自动置为「已结束」（`contest_auto_closed`，info 级审计，
  不点名任何人）。
* **从题目模式推导"保存规则"给选手看**。服务端不知道每台机器的 `scan.roots` 与
  文件名前缀，推导出来的"把代码存到 X"很容易是错的，而一条错的操作指引比没有指引更
  坏。公告改成教师写一份 `NOTICE.md` 下发（../design/05-api-and-frontend.md §5.6）。
