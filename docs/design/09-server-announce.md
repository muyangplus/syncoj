## 11. 服务端主动通告

> **状态**：已实现（2026-11）。通告是**加一条更快的路**，不替代 Agent 自己探测的那条路（理由见下文「为什么不能只靠它」）。
> 报文与规矩见 `reference/protocol.md` 的「服务端主动通告」一节；取舍见 ADR-0015。
> 代码：服务端 `services/announce.py` + `api/agent.py` 的 `whoami`；Agent `syncoj_agent/announce.py`。

### 11.1 想要什么

§7.3 是**机器问、服务端答**：包里没带地址或连续几轮连不上时，Agent 广播探测，服务端签名应答。通告反过来：

* **服务端在局域网里广播**"我在这儿，地址是 X"；
* **Agent 一直听着**，听到后核实并切换。

动机：服务端换 IP（DHCP、换一台机器当服务端）后，探测要等每台 Agent 连续失败三轮（约 35 秒）才各自去问；通告让 50 台机器在服务端上线后一两秒内全部转过来。

### 11.2 协议

**通告**（服务端 → 子网广播，UDP 端口 `45872`，与发现端口分开；报文 ≤ 512 字节）::

    {"syncoj": …, "v": …, "kind": "announce", "url": "http://10.0.0.5:8000",
     "key_id": "<公钥指纹>", "boot_id": "<本次启动的随机数>"}

**通告不签名**，只是线索。Agent 收到后：

1. 过滤：`key_id` 不是本机信任锚指纹 → 丢（隔壁考场）；`url` 与在用的相同 → 丢；同一 `boot_id` 处理过 → 丢；每分钟最多认真处理一次。
2. **挑战应答**：`GET <url>/api/v1/agent/whoami?nonce=<Agent 现生成的 32 位 hex>`，**不带凭据**。服务端用发布私钥签 `syncoj-announce-v1\n<nonce>\n<url>`（版本前缀与发现、发布签名不同，做跨协议隔离），其中 `url` 是**服务端自己认定的对外地址**（§7.3 三条来源）。Agent 验签后切到**签名里的地址**，因此请求被转发给真服务端时也只会指回真服务端。`whoami` 不鉴权、每次一次 RSA 签名，所以按来源 IP 限速。
3. 切换只在进程内生效，不写回 `agent.ini`（同 §7.3 的运行时重新发现）。

用挑战应答而非给通告签名：通告是服务端单方面发出，没有 Agent 的随机数，签名挡不住**重放**（录下真通告，等那个 IP 被 DHCP 分给自己再放出，机器会把注册密钥和代码送过去）；带时间戳又要求考试机时钟准，而还原卡机房时钟常差几小时。挑战应答让"此地址此刻握着私钥"成为切换前提，伪造或重放通告只浪费一次 HTTP 请求。

**服务端何时发**：启动后前 10 分钟每 30 秒一次，之后每 5 分钟一次；管理界面「召集机器」立即发一次。报文无 UDP 应答（Agent 的回应是 HTTP 请求），没有放大面。

### 11.3 为什么不能只靠它

* **开机顺序**：通告是瞬时的；服务端先开、考试机后开是常态，所以周期通告必不可少。
* **装机时**：安装器那几十秒里不会恰好有通告，而包里没带地址时它必须当场拿到地址，所以安装器的主动探测保留。
* **听不到的网络**：ufw 默认拒收入站 UDP，有些交换机隔离广播；通告是入站会被挡，探测是出站不受影响。这类机房只能靠机器自己问（或 `--discover-address` 单播）。
* 所以 Agent 探测保留为兜底，**阈值不放宽**（仍是连续失败约 35 秒）：放宽只会让收不到通告的机房变慢。

### 11.4 Agent 侧的代价

* **常驻监听一个 UDP 端口**：选手账号能绑 >1024 端口，`RestrictAddressFamilies=AF_INET AF_INET6` 允许 UDP，单元不用改。这是 Agent 唯一对外暴露的入口，输入一律不可信：限长 512 字节、只认那几个键、限速；最坏是被诱导去 GET 一个固定路径（不带凭据，验过签才用凭据连）。
* **线程**：监听放守护线程，只往线程安全的"候选地址"槽里放东西、什么都不连；主循环每轮开头看一眼槽。Agent 仍近乎无状态。
* 本机选手伪造通告会被挑战应答挡住，最多让 Agent 每分钟多发一次失败的 HTTP 请求。

### 11.5 落地顺序（已完成）

1. 服务端：`/api/v1/agent/whoami` 挑战应答端点（不鉴权，签名文本风格同 `services/discovery.py`、新前缀）；周期通告任务；「召集机器」按钮。
2. Agent：监听线程 + 候选地址槽；切换前挑战应答。
3. 测试：伪造 / 重放通告不切换；`key_id` 不符不切换；挑战应答失败不切换；通告与探测并存不打架；systemd 245 冒烟里关掉局域网发现、服务端换端口重启，机器靠通告转过去。
4. 文档：§7.3、协议参考、ADR-0015。
