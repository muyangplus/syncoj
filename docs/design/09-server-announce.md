## 11. 服务端主动通告

> **状态**：已实现（2026-11）。通告是新增的更快路径，不替代 Agent 主动探测（见下文「保留 Agent 主动探测」）。
> 报文与规矩见 `reference/protocol.md` 的「服务端主动通告」一节；取舍见 ADR-0015。
> 代码：服务端 `services/announce.py` + `api/agent.py` 的 `whoami`；Agent `syncoj_agent/announce.py`。

### 11.1 目标

* §7.3 是**机器问、服务端答**：包里没带地址或连续几轮连不上时，Agent 广播探测，服务端签名应答。
* 通告方向相反：**服务端在局域网广播**自己的地址；**Agent 常驻监听**，核实后切换。
* 效果：服务端换 IP（DHCP、换一台机器当服务端）后，50 台机器在服务端上线后一两秒内全部转过来；仅靠探测需每台 Agent 连续失败三轮（约 35 秒）。

### 11.2 协议

**通告**（服务端 → 子网广播，UDP 端口 `45872`，与发现端口分开；报文 ≤ 512 字节）::

    {"syncoj": …, "v": …, "kind": "announce", "url": "http://10.0.0.5:8000",
     "key_id": "<公钥指纹>", "boot_id": "<本次启动的随机数>"}

**通告不签名**，只是线索。Agent 收到后：

1. 过滤：`key_id` 不是本机信任锚指纹 → 丢（隔壁考场）；`url` 与在用的相同 → 丢；同一 `boot_id` 处理过 → 丢；每分钟最多处理一次。
2. **挑战应答**：`GET <url>/api/v1/agent/whoami?nonce=<Agent 现生成的 32 位 hex>`，**不带凭据**。服务端用发布私钥签 `syncoj-announce-v1\n<nonce>\n<url>`（版本前缀与发现、发布签名不同，跨协议隔离），`url` 是**服务端自己认定的对外地址**（§7.3 三条来源）。Agent 验签后切到**签名里的地址**（请求被转发给真服务端时也只会指回真服务端）。`whoami` 不鉴权、每次一次 RSA 签名，按来源 IP 限速。
3. 切换只在进程内生效，不写回 `agent.ini`（同 §7.3 的运行时重新发现）。

- 决定：挑战应答，让"此地址此刻持有私钥"成为切换前提；伪造或重放通告只浪费一次 HTTP 请求。
- 否决给通告签名：通告无 Agent 随机数，挡不住**重放**（录下真通告，待该 IP 被 DHCP 分给自己再放出，机器会送出注册密钥和代码）。
- 否决签名 + 时间戳：要求考试机时钟准确，还原卡机房时钟常差几小时。

**发送时机**：启动后前 10 分钟每 30 秒一次，之后每 5 分钟一次；「机器配对」→「召集机器」或顶栏「快捷操作」→「召集机器」立即发一次。通告无 UDP 应答（Agent 回应是 HTTP 请求），无放大面。

### 11.3 保留 Agent 主动探测

决定：Agent 探测保留为兜底，**阈值不放宽**（仍为连续失败约 35 秒；放宽只会让收不到通告的机房变慢）。否决只靠通告：

* **开机顺序**：通告是瞬时的；服务端先开、考试机后开是常态，需周期通告。
* **装机时**：安装器运行的几十秒内不一定有通告，包里没带地址时须当场拿到地址，保留安装器主动探测。
* **收不到的网络**：ufw 默认拒收入站 UDP，部分交换机隔离广播；通告（入站）被挡，探测（出站）不受影响。此类机房只能靠机器主动问（或 `--discover-address` 单播）。

### 11.4 Agent 侧的代价

* **常驻监听一个 UDP 端口**：选手账号能绑 >1024 端口，`RestrictAddressFamilies=AF_INET AF_INET6` 允许 UDP，单元不用改。这是 Agent 唯一对外入口，输入一律不可信：限长 512 字节、只认固定键、限速；最坏情况是被诱导 GET 一个固定路径（不带凭据，验签通过后才用凭据连）。
* **线程**：监听在守护线程，只写线程安全的"候选地址"槽、不发起连接；主循环每轮开头读取该槽。
* 本机选手伪造通告会被挑战应答挡住，最多让 Agent 每分钟多发一次失败的 HTTP 请求。

### 11.5 落地顺序（已完成）

1. 服务端：`/api/v1/agent/whoami` 挑战应答端点（不鉴权，签名文本风格同 `services/discovery.py`、新前缀）；周期通告任务；「召集机器」操作。
2. Agent：监听线程 + 候选地址槽；切换前挑战应答。
3. 测试：伪造 / 重放通告不切换；`key_id` 不符不切换；挑战应答失败不切换；通告与探测并存不打架；systemd 245 冒烟里关掉局域网发现、服务端换端口重启，机器靠通告转过去。
4. 文档：§7.3、协议参考、ADR-0015。
