# 快速上手（教师）

## 教师上手流程

界面里就能走完，命令行也可以（便于脚本化批量部署）：

```bash
# ── 界面 ──────────────────────────────────────────────
# 1. syncoj-server init                建库 + 建管理员
# 2. 打开 http://<服务端>:8000          登录（管理界面只在这个端口上）
#                                      考生机器上的地址是 http://<服务端>/（默认 80）
# 3. 场次管理 → 新建场次
#                                      可选：指定默认名单、填开考/结束时间
# 4. 名单库 → 新建名单 → 粘贴导入        （从 Excel 直接粘）
#                                      再回场次管理点「设置」选这份名单
# 5. 场次管理 → 进入 → 「应用名单」      （把名单落到这个场次）
# 6. 场次管理 → 题目                  → 登记题目（标识会用作目录名与代码文件名）
#                                      按需填「代码路径」，拿不准就留空
# 7. 装 Agent（见 `../install-agent.md`）
#      syncoj-server bootstrap-key issue --out /etc/syncoj/bootstrap.key
#      → 把密钥放进镜像（root 只读）→ 机器开机
# 8. 机器配对 → 对着机器上显示的六位配对码，认领到名单里的人
```

## 两个端口

| 端口 | 上面有什么 | 谁用 |
|---|---|---|
| `--port`（默认 **8000**） | 管理界面 + 全部 API + `/docs` | 教师 |
| `SYNCOJ_PUBLIC_PORT`（默认 **80**） | 只有 `/install` 与 `/player` | 考场机器 |

考场机器上的地址就是 `http://10.0.0.5/` —— 浏览器对 http 默认走 80，学生连端口都不用
敲。这个端口上**没有登录框、也没有接口地图**（管理端、`/docs`、`/openapi.json` 一律
404）。

`SYNCOJ_PUBLIC_PORT=0` 可以关掉第二个监听（`0` 是"关掉"的哨兵：留空等于没设，会退回
默认的 80）。80 是特权端口：服务端跑在专用账号下
时绑不上，这时它会**降级**（管理端口照常）并打印两种修法 —— `AmbientCapabilities=
CAP_NET_BIND_SERVICE`，或者换一个非特权端口。详见 ../design/05-api-and-frontend.md §5.7。

配对是**永久**的：绑的是**人**（名单条目），不是某场比赛的选手。换一场比赛不用
重配，只要新场次也应用了那份名单；机器下一次 tick 就会自己拿到新的场次身份。

## 目录约定

默认落点：`桌面/<准考证号>/<题目名>/<题目名>.cpp`；回收后在服务端的落点是
`source/<场次>/<准考证号>/<题目名>/<题目名>.cpp`。

- 这只是默认值：下发落哪、从哪收、怎么归题三层都可以改。
- 题面/样例默认下发到桌面根目录，按 zip 原样落盘（服务端不解压）。

题面需要密码时，在「文件下发」里对 `.zip` 点「密码」：服务端就地打密码 / 改密码，
并生成或更新一份 `password.txt`，把它一起下发即可。算法与口径见
[`design/05-api-and-frontend.md §5.5`](design/05-api-and-frontend.md)。

三层配置、路径模板占位符与 glob 归题规则的完整说明见
[`design/04-server.md §4.5`](design/04-server.md)。装机视角的同一件事见
[`install-agent.md`](install-agent.md)。
